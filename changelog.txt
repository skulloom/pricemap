[7.9]
- 맵핑 완료 시 조회 결과 팝업(성공/실패 요약) → 확인 후 지도 열기
- 지도 저장·지번정보 저장에 각각 저장 완료 팝업 표시
- 같은 폴더 저장 체크 시 창 높이 자동 조절 (빈 공간 제거)
- 저장 안 한 임시 지도가 종료 시 안 지워지던 문제 수정 + 시작 시 잔재 자동 청소

[7.8]
- 하단 실행 영역 디자인 정리 — 카드형 통합, 진행바를 버튼 위 전체 너비로, 버튼 모양 통일

[7.7]
- 하단 버튼 정리: 작업 중엔 일시중지·중지만 표시 (버튼 겹침 깨짐 수정)
- 저장 버튼(지도·지번정보)은 맵핑 후에만 활성화

[7.6]
- 조회 속도 대폭 개선 — 병렬 처리 (60필지 기준 약 70초 → 1~2초)
- 버튼 개편: [맵핑] 공시지가 자동 조회+지도 열기(임시) / [지도 저장] / [지번정보 저장](엑셀)
- 저장 안 한 임시 지도는 프로그램 종료 시 자동 삭제

[7.5]
- 직접 붙여넣기 모드에서 지도 보기 시 빈 화면 뜨던 문제 수정 (저장 폴더 미지정 버그)

[7.4]
- 도로명 변환 실패 시 원인 안내 표시 (없는 주소 등) — 상태 글자 잘림 수정

[7.3]
- 도로명 주소 자동 변환 — 붙여넣은 도로명(예: 첨단과기로 208번길 43-22)을 지번으로 자동 변환
- 도로명 뒤 건물명(예: 와이어스파크)은 시설명으로 자동 분류

[7.2]
- 화면 디자인 개편 (카드형 레이아웃, 밝은 미리보기 표)
- 지번 직접 붙여넣기 입력 추가 — 자유 형식 텍스트 자동 인식·분리
- 구역명(예: A구역)으로 필지 묶기 — 지도 그룹에 사용, 표에서 수정 가능

- 업데이트 알림·완료 팝업에 변경사항 표시
- 파일 속성(자세히 탭)에 버전 정보 표시
